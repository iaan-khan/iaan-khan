## 🧠 Engineering Principles

```text
Business problem
      │
      ▼
Domain model
      │
      ▼
Application use cases
      │
      ├── Commands / Queries
      ├── Validation
      └── Authorization
      │
      ▼
Infrastructure
      │
      ├── Database
      ├── Messaging
      ├── Cache
      ├── Cloud services
      └── External services
      │
      ▼
API / UI / Integrations
```

I prioritize:

- Clear separation of concerns
- Explicit business rules
- Testable application logic
- Secure APIs and cloud configurations
- Reliable distributed communication
- Practical scalability
- Observability
- Maintainable code over unnecessary complexity
